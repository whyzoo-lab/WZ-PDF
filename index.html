Add it to your site

One <iframe> is all it takes. Put your PDF URL (encoded) in url.

urlthe PDF to display (encode with encodeURIComponent) filealias for url embed=1hide the editing chrome (read-only). Omit it to open the full viewer.
⚠️ CORS note: the web build fetches the PDF in the browser, so the PDF host must allow cross-origin access. The safest setup is to serve the viewer and the PDF from the same domain — upload the npm run build output (dist/) to your site and keep the PDF on the same origin. The desktop (Electron) app is not affected by CORS.
