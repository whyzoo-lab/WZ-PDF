내 사이트에 넣는 방법

아래 <iframe> 한 줄이면 끝입니다. url에 PDF 주소를 인코딩해 넣으세요.

url표시할 PDF 주소 (encodeURIComponent로 인코딩) fileurl 별칭 embed=1편집 크롬 숨김(읽기 전용). 빼면 전체 뷰어로 열림
⚠️ CORS 주의: 웹 빌드는 브라우저 fetch로 PDF를 가져오므로 PDF 호스트가 외부 접근(CORS)을 허용해야 합니다. 가장 안전한 방법은 뷰어와 PDF를 같은 도메인에서 서빙하는 것입니다 — npm run build 결과(dist/)를 사이트에 올리고 PDF도 같은 출처에 두세요. 데스크톱(Electron) 앱은 CORS 영향을 받지 않습니다.
