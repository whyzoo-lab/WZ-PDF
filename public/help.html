파일 열기

PDF 파일을 여는 다섯 가지 방법
  • 🖱️ 상단 Open 버튼을 클릭하고 파일을 선택하세요.
  • ⌨️ F2 키를 누르면 파일 선택 창이 바로 열려요.
  • 🗂️ PDF 파일을 창 위로 드래그해서 놓으면 바로 열립니다.
  • 💻 파일이 없는 빈 화면을 더블클릭해도 파일 선택 창이 열려요.
  • 📁 윈도우 탐색기에서 PDF 파일을 더블클릭하면 WZ PDF가 자동으로 열립니다. (설치 버전만 해당)
  • 🔗 상단 Open ▾ → URL로 열기에서 PDF 직접 링크를 붙여넣으면 인터넷에 있는 PDF를 바로 불러와요. (해당 사이트가 외부 접근을 막아둔 경우엔 파일을 내려받아 여세요)

보기 방식

상황에 맞게 화면 구성을 바꿔보세요
📄
한 장 보기
한 페이지씩 위아래로 스크롤해요. 기본 보기 방식이에요.
📖
두 장 나란히
두 페이지를 좌우로 펼쳐서 봐요. 책처럼 볼 때 좋아요.
🗂️
전체 보기
모든 페이지를 한눈에 볼 수 있어요. 클릭하면 해당 페이지로 이동해요.
🎬
전체화면
화면 가득 채워서 봐요. 발표·프레젠테이션에 딱 맞아요.
💡 화면 크기 조절: Ctrl + 마우스 휠을 굴리면 확대·축소돼요. 상단 + / – 버튼이나 회전 버튼으로도 조절할 수 있어요.
🎬 전체화면 진입: 상단 메뉴에서 선택하거나 F5 키를 누르세요.
📄

페이지 관리

왼쪽 패널에서 탐색하고 편집해요 — 편집 모드에서만 수정 가능해요
🖱️페이지 이동
왼쪽 목록에서 원하는 페이지 썸네일을 클릭하면 바로 이동해요.
↕️순서 바꾸기
썸네일을 위아래로 드래그해서 페이지 순서를 자유롭게 바꿀 수 있어요.
➕페이지 추가
빈 페이지를 끼워 넣거나, 다른 PDF 파일의 페이지를 가져올 수 있어요.
🗑️페이지 삭제
지우고 싶은 페이지를 선택하고 Delete 키 또는 삭제 버튼을 누르세요.
✅ 여러 페이지 한번에 선택: Ctrl 또는 Shift를 누른 채로 클릭하면 여러 페이지를 동시에 선택할 수 있어요.
💡 걱정 마세요: 페이지를 삭제하거나 순서를 바꿔도 도장·서명 같은 표시들이 자동으로 따라가요. 워터마크도 그대로 유지돼요.
🔍

텍스트 인식 (OCR)

스캔한 문서·이미지 PDF에서 글자를 읽어내요 — 한국어·영어 지원

글자가 이미지로 들어 있어 복사·검색이 안 되는 PDF에서도, OCR을 돌리면 글자를 인식해 선택하고 복사할 수 있게 돼요. 별도 프로그램이나 인터넷 연결 없이 기기 안에서 바로 처리됩니다.

📄현재 페이지 인식
상단 OCR 메뉴에서 현재 페이지를 선택하면 지금 보고 있는 페이지만 빠르게 인식해요.
📚전체 문서 인식
전체 문서를 선택하면 모든 페이지를 차례로 인식해요. 진행 상황이 표시되고, 도중에 취소할 수 있어요.
🖱️선택 · 복사
인식이 끝나면 글자 위를 드래그해 선택하고 복사할 수 있어요. 원본 글자 위치에 맞춰 자연스럽게 잡혀요.
✅ 완전 오프라인: 인식은 모두 기기 안에서 처리돼요. 문서가 외부로 전송되지 않아 안심하고 쓸 수 있어요.
💡 이미 글자가 있는 PDF라면: OCR 없이도 Ctrl+F로 바로 검색할 수 있어요. OCR은 스캔본·사진처럼 글자가 이미지로 된 경우에 사용하세요.
📱 휴대폰에서: 페이지가 크거나 기기 메모리가 빠듯하면 인식이 느리거나 멈출 수 있어요. 큰 문서는 PC에서 처리하는 것을 권장해요.
🖊️

도장 · 서명 · 워터마크 넣기

PDF에 영구적으로 남는 표시 — 편집 모드에서 사용 가능해요
📮도장 넣기
도장 아이콘을 클릭해 원하는 도장을 고르고, PDF의 원하는 위치를 클릭하면 찍혀요. 크기와 방향도 자유롭게 조절할 수 있어요.
✍️서명 넣기
서명 아이콘을 클릭하면 팝업이 열려요. 마우스나 터치로 직접 서명을 그린 뒤 원하는 위치에 올려놓으세요.
🔏워터마크 넣기
문서 전체에 반투명 텍스트를 깔아요. 문구, 글자 크기, 색상, 각도를 설정하면 모든 페이지에 자동으로 적용돼요.
✅ 표시 삭제: 도장이나 서명을 클릭해서 선택한 뒤 Delete 또는 Backspace 키를 누르면 지워져요.
💡 저장해야 반영돼요: 이 표시들은 PDF로 저장해야 파일에 최종 반영됩니다. 아래 저장하기 를 참고하세요.
✏️

화면 필기 도구

발표·강의 중 강조 표시용 — 파일에 저장되지 않아요

화면에서 일시적으로 그릴 수 있는 도구예요. 발표 중 중요한 부분을 가리키거나 강조할 때 유용해요. PDF 파일에는 저장되지 않아서 언제든 깔끔하게 지울 수 있어요.

🖌️1 노란 형광펜
마우스를 드래그하면 반투명 노란색으로 자유롭게 그려져요. 1 키를 다시 누르면 모드가 꺼져요.
⬜2 빨간 사각형
드래그하면 빨간 테두리 사각형이 그려져요. 강조할 영역을 네모로 감쌀 때 편해요. 2 키를 다시 누르면 꺼져요.
🧹 모두 지우기: ESC 키를 누르면 그린 내용이 모두 사라지고 그리기 모드도 꺼져요. 상단의 Reset 버튼을 눌러도 같은 효과예요.
💡 전체화면에서 사용 중이라면: ESC를 한 번 누르면 필기가 지워지고, 한 번 더 누르면 전체화면에서 빠져나와요.
🎯

발표 도구

전체화면에서 쓰는 강조 도구 모음 — 발표·강의에 딱 맞아요

F5로 전체화면에 들어가면 발표용 강조 도구가 켜져요. 키보드 한 글자로 도구를 바꿔가며 화면에 그리거나, 레이저로 가리키거나, 특정 부분을 확대할 수 있어요. 모든 표시는 화면에만 보이고 PDF에는 저장되지 않아요.

✒️P 펜
드래그해서 자유롭게 선을 그려요. 핵심을 짚어줄 때 좋아요.
🖍️H 형광펜
반투명 굵은 선으로 글자 위를 칠해 강조해요.
▭R 사각형
드래그한 영역을 네모로 감싸 강조해요.
➤A 화살표
시작점에서 끝점까지 화살표를 그려 특정 지점을 가리켜요.
🔴L 레이저 포인터
마우스를 따라다니는 빨간 점이 떠요. 자국을 남기지 않고 가리킬 때 써요.
🔎Z 스팟 줌
마우스 위치를 중심으로 화면을 확대해요. Ctrl+휠로 배율을 조절할 수 있어요.

그리기 도구를 쓰는 동안 색과 굵기를 바로 바꿀 수 있어요.

🎨1~5 색상
빨강 · 초록 · 파랑 · 노랑 · 주황으로 펜·형광펜·사각형·화살표 색을 바꿔요.
↔️[ ] 굵기
[는 가늘게, ]는 굵게. 선 굵기를 단계별로 조절해요.
↩️Ctrl+Z · E
Ctrl+Z는 마지막 선 하나를 지우고, E는 그린 것을 모두 지워요.
💡 같은 키를 다시 누르면 꺼져요: 예를 들어 P를 한 번 더 누르면 펜이 꺼지고 일반 보기로 돌아와요.
⎋ ESC 두 단계: 그린 내용이나 켜진 도구가 있으면 ESC 한 번으로 모두 정리돼요. 깨끗한 상태에서 ESC를 한 번 더 누르면 전체화면에서 빠져나와요.

저장하기

상단 Export 메뉴에서 원하는 방식을 선택하세요
📄
PDF로 저장
도장, 서명, 워터마크가 포함된 PDF 파일로 저장해요. 가장 많이 쓰는 저장 방식이에요.
🌐
HTML 파일로 저장
웹 브라우저만 있으면 어디서든 열어볼 수 있는 단일 HTML 파일로 저장해요. 별도 프로그램 없이 공유할 때 편해요.
🖼️
이미지로 저장
각 페이지를 고해상도 PNG 이미지로 변환해 ZIP 파일로 묶어서 저장해요. 이미지 편집이나 삽입이 필요할 때 유용해요.
📦
뷰어 EXE로 저장
PDF가 내장된 독립 실행 파일(.exe)로 저장해요. 받는 사람이 더블클릭만 하면 WZ PDF 없이도 문서가 바로 열려요.
포터블(휴대용) 버전에서만 사용 가능
🖨️

인쇄하기

도장·서명·워터마크가 포함된 상태로 인쇄돼요

상단의 Print 버튼을 클릭하거나 Ctrl+P 단축키를 누르면 인쇄 창이 열려요. 화면에 보이는 표시가 그대로 인쇄되니, 먼저 잘 배치됐는지 확인하고 인쇄하세요.
