파일 열기

PDF, 한글, Word, PowerPoint, Excel, 메일, Markdown, 이미지를 모두 열어요

열 수 있는 형식: PDF · 한글(.hwp .hwpx) · Word(.docx) · PowerPoint(.pptx) · Excel(.xlsx .xls .ods .csv) · 메일(.eml) · Markdown(.md) · 이미지(jpg png gif bmp webp tiff). Office나 한컴오피스가 없어도 돼요.

  • 🖱️ 상단 📂 파일 열기 버튼을 누르거나 F2 키를 누르세요.
  • 🗂️ 파일을 창 위로 드래그해서 놓으면 바로 열려요.
  • 🕘 시작 화면의 최근 파일 목록에서 다시 열 수 있어요. (데스크톱 앱)
  • 📁 윈도우 탐색기에서 파일을 더블클릭하면 WZ Reader로 열려요. (설치 버전)
  • 🔗 📂 ▾ → URL로 열기에 문서 링크를 붙여넣으면 인터넷에 있는 문서를 바로 불러와요. (사이트가 외부 접근을 막아 두었다면 내려받아 여세요)
🔐 비밀번호가 걸린 PDF는 열 때 비밀번호를 물어봐요. 자세한 건 비밀번호를 보세요.
🖼️ 이미지를 열면 같은 폴더의 이미지가 함께 페이지 목록에 올라와요. 이전·다음은 PDF 페이지 넘기듯 하면 되고, 여러 장을 한꺼번에 고르거나 끌어 놓아도, 이미지 ZIP을 열어도 한 문서가 돼요. PDF로 저장하면 모두 한 PDF로 묶여요. 여러 쪽 TIFF, 투명 PNG, 움직이는 GIF도 그대로 보여요.
🐘 500 MB가 넘는 큰 PDF도 열려요(약 2 GB까지). 필요한 부분만 읽어서 빠르게 열리고, 대신 보기 전용이에요. (데스크톱 앱)

보기 방식

상황에 맞게 화면 구성을 바꿔 보세요
📄
한 장 보기
한 페이지씩 위아래로 스크롤해요. 기본 보기 방식이에요.
📖
두 장 보기
두 페이지를 좌우로 펼쳐서 봐요. 가로로 넓은 페이지는 혼자 한 줄을 써요.
🗂️
전체 보기
모든 페이지를 한눈에 봐요. 클릭하면 그 페이지로 이동해요.
🎬
전체화면
화면 가득 채워서 봐요. 발표·프레젠테이션에 딱 맞아요.
💡 확대·축소: Ctrl + 마우스 휠, 또는 상단 + / – 버튼. 너비 맞춤 버튼을 누르면 글자가 더 선명하게 크게 보여요.
🔎 찾기: Ctrl+F로 문서 안의 글자를 찾아요. 모든 형식에서 돼요.
🎬 전체화면: F5는 첫 쪽부터, Alt+F5는 지금 보고 있는 쪽부터 시작해요.

Word · PowerPoint · Excel

Office 없이 원래 모양 그대로 — 표, 차트, 그림까지
📝Word
Word가 나누는 대로 페이지가 나뉘고, 머리말·꼬리말과 글머리 기호도 그대로 나와요.
📽️PowerPoint
슬라이드를 PowerPoint와 같은 모습으로 보여 줘요. 숨긴 슬라이드는 슬라이드쇼에서 건너뛰어요.
📈Excel
글꼴, 색, 테두리, 병합 셀, 숫자 형식이 그대로예요. 20만 줄이 넘는 큰 시트도 모든 줄을 볼 수 있어요.

Word와 PowerPoint는 PDF처럼 한 장 · 두 장 · 전체 보기, 쪽 번호, 왼쪽 페이지 목록을 쓸 수 있어요.

🗒️발표자 노트
노트가 있는 발표 자료는 각 슬라이드 아래에 노란 상자로 보여요. 상단 노트 버튼으로 켜고 끄세요.
💬슬라이드쇼 자막
전체화면 슬라이드쇼에서는 노트가 자막처럼 아래에 떠요. C 키나 오른쪽 아래 버튼으로 켜고 꺼요.
🎬발표 동영상
노트가 있는 발표 자료는 필름 버튼으로 MP4 동영상으로 저장해요. 노트를 읽는 목소리와, 켜고 끌 수 있는 자막이 들어가요. (데스크톱 앱)
💾 세 형식 모두 PDF로 저장하면 글자를 선택하고 검색할 수 있는 PDF가 만들어져요.
✉️

메일 · Markdown

받은 메일과 메모 문서도 문서처럼
✉️메일 (.eml)
보낸 사람, 받는 사람, 본문이 나오고 첨부 파일은 저장하거나 바로 열 수 있어요. 한글 메일(EUC-KR)도 깨지지 않아요.
🛡️바깥 그림 차단
메일 속 인터넷 그림은 누르기 전까지 불러오지 않아요. 열어 본 사실이 보낸 사람에게 알려지지 않게요.
📝Markdown (.md)
제목, 표, 코드, 체크리스트가 정리된 문서로 보이고, 왼쪽 목차가 읽는 위치를 따라와요.
✏️Markdown 편집
상단 연필 버튼을 켜면 원문을 고칠 수 있어요. Ctrl+S로 .md 파일에 저장해요.
💡 메일과 Markdown도 인쇄·찾기·전체화면·읽어 주기·PDF로 저장이 돼요. 인쇄와 PDF는 글자 그대로 나와서 선명하고 선택할 수 있어요.

읽어 주기

자연스러운 목소리로 문서를 읽어 줘요 — 인터넷 없이 PC 안에서

상단 🔊 스피커 버튼이나 S 키(또는 Alt+S)를 누르면 지금 보고 있는 곳부터 한 문장씩 읽어요. 읽는 문장은 화면에 표시되고, 화면도 따라 움직여요.

🎙️목소리 · 속도
목소리 10가지와 속도를 고른 뒤 적용을 누르면 다음 문장부터 바뀌어요.
⏮️앞뒤로 이동
Alt+← 이전 문장, Alt+→ 다음 문장, Alt+Space 일시정지/계속. 읽는 중에 ESC를 누르면 일시정지해요.
📽️발표 자료
PowerPoint에 발표자 노트가 있으면 슬라이드 대신 노트(대본)를 읽어요. 전체화면에서는 읽는 대로 페이지가 넘어가요.
📷스캔 문서
글자가 그림인 문서는 먼저 글자 인식을 하면 인식한 글자를 읽어요.
📥 처음 한 번 목소리 파일(383 MB)을 내려받을지 물어봐요. 그다음부터는 인터넷 없이 동작하고, 읽는 내용은 PC 밖으로 나가지 않아요. (데스크톱 앱)
📄

페이지 관리

왼쪽 페이지 목록에서 탐색하고 편집해요 — 추가·삭제·순서 바꾸기는 PDF와 이미지
🖱️페이지 이동
왼쪽 목록에서 썸네일을 클릭하면 바로 이동해요.
↕️순서 바꾸기
썸네일을 위아래로 드래그해서 순서를 바꿔요. (편집 모드)
➕페이지 추가
빈 페이지를 끼워 넣거나 다른 PDF의 페이지를 가져와요. 이미지 문서에서는 이미지 추가로 그림을 더 넣어요. (편집 모드)
🗑️페이지 삭제
페이지를 선택하고 Delete를 누르세요. 실수했다면 Ctrl+Z로 되돌려요. (편집 모드)
📤선택 저장
페이지를 선택하고 오른쪽 클릭 → 선택 저장하면 그 페이지만 새 PDF로 저장해요. 보기 모드에서도 돼요.
✅ 여러 페이지 선택: Ctrl 또는 Shift를 누른 채 클릭하세요.
💡 페이지를 지우거나 순서를 바꿔도 도장·서명이 그 페이지를 따라가요.
🔍

글자 인식 (OCR)

스캔한 문서·사진에서 글자를 읽어내요 — 한국어·영어

글자가 그림으로 들어 있어 복사·검색이 안 되는 문서도, 글자 인식을 하면 선택·복사·검색·읽어 주기가 돼요. 기기 안에서 처리되고 인터넷이 필요 없어요.

📄이 페이지
상단 글자 인식 버튼이나 R(또는 Alt+R). 페이지를 네 번 클릭해도 돼요.
📚전체 문서
버튼 옆 ▾ 메뉴에서 전체 문서, 또는 R를 두 번. 진행 상황이 보이고 취소할 수 있어요.
✂️영역만 복사
Ctrl를 누른 채 영역을 드래그하면 그 부분만 인식해서 클립보드에 복사해요.
💾PDF에 남기기
인식한 뒤 PDF로 저장하면 글자가 파일에 들어가서, 다른 PDF 프로그램에서도 검색·복사가 돼요.
💡 이미 글자가 있는 PDF는 글자 인식 없이 바로 찾기(Ctrl+F)가 돼요.

도장 · 서명 · 워터마크

파일에 남는 표시 — 상단 연필 버튼으로 편집 모드를 켜세요
📮도장
도장 버튼에서 기본 도장을 고르거나 이미지 업로드로 내 도장을 올려요. 페이지를 클릭할 때마다 찍혀요.
🗂️내 도장
올린 도장은 흰 배경을 지우고 여백을 잘라 내 도장에 저장돼요. 마지막으로 맞춘 크기도 기억해요.
✍️서명
서명 버튼을 누르고 마우스나 터치로 직접 그린 뒤 원하는 위치에 놓으세요.
🔏워터마크
문구, 크기, 색, 각도를 정하면 모든 페이지에 반투명 글자가 깔려요.
📋 모든 페이지에 같은 도장: 도장을 선택하고 Ctrl+C → 페이지 목록에서 여러 쪽을 고른 뒤 Ctrl+V. 같은 자리에 한꺼번에 찍혀요.
↩️ 되돌리기: Ctrl+Z, 다시 실행은 Ctrl+Y. 선택한 도장·서명은 Delete로 지워요. 도장 도구를 내려놓으려면 ESC.
💾 표시는 PDF로 저장해야 파일에 들어가요. 저장하지 않고 다른 문서를 열거나 닫으면 저장할지 물어봐요.
🔐

비밀번호

잠긴 PDF를 열고, 저장할 때 비밀번호를 걸거나 풀어요
🔓열기
비밀번호가 걸린 PDF를 열면 비밀번호를 물어봐요. 틀리면 다시 물어봐요.
🔒걸기 · 풀기
상단 자물쇠 버튼으로 다음 저장을 잠글지 정해요. 누르는 순간 저장되지는 않고, PDF로 저장할 때 적용돼요.
💡 처음부터 잠겨 있던 문서는 그대로 잠긴 채 저장돼요. 풀려면 자물쇠를 눌러 푼 뒤 저장하세요. 파일 이름에 _locked / _unlocked가 붙어요.

화면 필기

강조 표시용 — 파일에 저장되지 않아요
🖌️1 노란 형광펜
드래그하면 반투명 노란색으로 그려져요. 1을 다시 누르면 꺼져요.
⬜2 빨간 사각형
드래그해서 강조할 영역을 네모로 감싸요. 2를 다시 누르면 꺼져요.
🧹 모두 지우기: ESC를 누르거나 상단 지우개 버튼을 누르세요. 전체화면에서는 ESC 한 번 더 누르면 빠져나와요.
🎯

발표 도구

전체화면에서 쓰는 강조 도구 — 화면에만 보이고 저장되지 않아요
✒️P 펜
드래그해서 자유롭게 선을 그려요.
🖍️H 형광펜
반투명 굵은 선으로 글자 위를 칠해요.
▭R 사각형
드래그한 영역을 네모로 감싸요.
➤A 화살표
특정 지점을 화살표로 가리켜요.
🔴L 레이저 포인터
마우스를 따라다니는 빨간 점. 자국이 남지 않아요.
🔎Z 스팟 줌
마우스 위치를 확대해요. 휠로 배율을 조절해요.

그리는 동안 색과 굵기를 바로 바꿀 수 있어요.

🎨1~5 색상
빨강 · 초록 · 파랑 · 노랑 · 주황.
↔️[ ] 굵기
[ 가늘게, ] 굵게.
↩️Ctrl+Z · E
마지막 선 하나 지우기 · 모두 지우기.
💡 Word·메일·Markdown 전체화면은 한 화면씩 넘겨 읽어요. + / –로 글자 크기, 0으로 원래 크기. PowerPoint는 슬라이드쇼로 열려요.
⎋ ESC 두 단계: 그린 것이나 켜진 도구가 있으면 ESC 한 번으로 정리되고, 한 번 더 누르면 전체화면에서 나와요.

저장하기

저장 버튼 = PDF로 저장 (Ctrl+S) · 옆의 ▾ 메뉴에 나머지

어떤 형식이든 ▾ 메뉴에 같은 세 가지가 있어요: 원본 파일 저장, PDF로 저장, EXE로 내보내기. PDF·한글·이미지에는 책자·HTML·이미지 저장이 더 있어요.

🗎
원본 파일 저장
열어 둔 파일을 그대로 다른 이름으로 저장해요. PowerPoint는 .pptx로, 메일은 .eml로.
📄
PDF로 저장
도장·서명·워터마크와 인식한 글자까지 넣은 PDF로 저장해요. Word·PowerPoint·Excel·메일·Markdown도 글자를 선택할 수 있는 PDF가 돼요.
📚
책자 형태로 저장
두 장 보기 그대로, 한 장에 두 페이지씩 담은 PDF예요. 인쇄해서 접으면 책자가 돼요.
PDF · 한글 · 이미지
🌐
HTML 저장
브라우저만 있으면 열어 볼 수 있는 HTML 파일 하나로 저장해요.
PDF · 한글 · 이미지
🖼️
이미지 저장
각 페이지를 고해상도 PNG로 바꿔 ZIP으로 묶어요.
PDF · 한글 · 이미지
📦
EXE로 내보내기
열어 둔 문서를 담은 실행 파일(.exe)이에요. 원래 형식 그대로 담겨서 받는 사람이 더블클릭만 하면 설치 없이 열려요 — PowerPoint면 슬라이드쇼와 노트까지. 도장·서명을 찍었다면 그것까지 넣은 PDF가 담기고, 잠긴 PDF는 열 때 똑같이 비밀번호를 물어요.
데스크톱 앱(설치·포터블)
🎬 노트가 있는 PowerPoint는 필름 버튼으로 발표 동영상(MP4)도 만들 수 있어요. Word · PowerPoint · Excel을 보세요.
